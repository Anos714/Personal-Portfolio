# 🌐 Personal Portfolio Website

A sleek and responsive personal portfolio website built using **HTML**, **CSS**, and **JavaScript**. This project highlights my work, skills, and provides a way for others to connect with me.

## 🚀 Features

- Fully responsive design for all devices
- Smooth scrolling and interactive elements
- Project showcase section
- About Me and Contact sections
- Hosted on GitHub Pages

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Git & GitHub
